# Hicks Help

Customer-facing Duramax guidance and public Hicksville Auto Recyclers inventory.

This package updates the existing **public Hicks Help submission** in the OpenAI
developer dashboard. Upload it through that submission's package update flow.
The intended customer experience is ordinary ChatGPT on the web through the
hosted HTTPS MCP connection at `https://hicksvilleautorecyclers.com/api/mcp`.
It requires no local server, desktop executable, OpenAI API key or HAR staff
login. The root `plugin.json` supplies the public listing and review information;
`mcp.json` supplies the remote connection. Public review and publication must
finish before the directory listing is available to customers.

Try: “Find complete Allison transmissions at HAR.” Then give your truck’s year,
model, engine/RPO and 2WD/4WD so fitment can be reviewed. Or ask: “What should I
confirm before ordering a rebuilt Duramax?”

The tools search public stock, recheck a listing and retrieve HAR knowledge.
They cannot submit requests, message staff, reserve stock, pay or access customer
records. Guides are not a repair manual or a diagnosis; prices and availability
come from a fresh inventory read. Call HAR at 419-542-8500 to confirm an order.

HAR's website currently displays Coming Soon without preview access. Product
links may display that screen. This plugin does not bypass the website
gate. Public directory publication and review are separate from importing this
archive; they have not been completed.

Support: https://hicksvilleautorecyclers.com/hicks-help#support

Version 0.1.4 includes the owner-supplied browser walkthrough URL, all supported
countries, the English listing, five positive cases, three negative cases and
commerce details. The clip demonstrates transmission shopping and related parts;
it does not establish completion of every review case. Public submission and
approval remain separate from preparing or uploading this package.

Once installed and connected, start a new chat. ChatGPT can choose installed
tools for relevant tasks; type `@Hicks Help` to select this plugin explicitly.
